# تصاویر هدهد

این فایل‌ها از خود برنامه گرفته شده‌اند؛ رابط طراحی‌شده یا mockup تصویری نیستند.

| [گفتگوی موبایل](hodhod-connected-mobile.png) | همان جریان در چت داخل صفحهٔ خرید |

تصاویر `hodhod-urgent-*` و `hodhod-visit.png` در آزمون مرورگر ثبت شده‌اند. کالاها از دیتاست‌اند ولی بعضی پاسخ‌های مسیریابی این آزمون‌ها کنترل‌شده هستند؛ این تصاویر شاهد دسترس‌پذیری زندهٔ مسیریاب یا موجودی تأییدشدهٔ فروشگاه نیستند. `map-offline.png` حالت قطع سرویس نقشه را نشان می‌دهد.

برای ثبت دوبارهٔ دو تصویر گفتگوی متصل، برنامه و بک‌اند را با `AGENT_MODE=grounded` اجرا کنید، سپس از ریشهٔ مخزن:

```bash
SCREENSHOT_BASE_URL=http://127.0.0.1:5173 node scripts/capture-screenshots.mjs
```

مرورگر پیش‌فرض روی ویندوز Edge است؛ در محیط دیگر `PLAYWRIGHT_BROWSER_PATH` را تنظیم کنید یا Chromium Playwright را نصب کنید. اسکریپت از نشست تمیز و یک درخواست عمومی استفاده می‌کند و چت‌های شخصی کاربر را نمی‌خواند.
